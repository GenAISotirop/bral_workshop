Qwen · BRaL Workshop

Build-Refine-Learn με Qwen Projects · Γ' Γυμνασίου

Σε αυτό το workshop θα φτιάξετε διαδραστική προσομοίωση φυσικής με το Qwen. Το Qwen υποστηρίζει Projects και Artifacts — το AI καθοδηγεί με ερωτήσεις και φτιάχνει διαδραστικές προσομοιώσεις που τρέχουν αμέσως!

⚙️ Προετοιμασία: Setup Qwen Project

Βήμα 1: Δημιουργία Project

  1. Πηγαίνετε στο qwen.ai
  2. 3 τελίτσες (⋮) πάνω δεξιά → Edit Project
  3. Στο πεδίο Project Name: BRaL Γυμνάσιο - Φυσική

Βήμα 2: Προσθήκη Βασικών Οδηγιών

Στο πεδίο Instructions (ή System Prompt), επικολλήστε το παρακάτω:

📋 SHORT INSTRUCTIONS (για το Instructions field)
Είσαι εκπαιδευτικός βοηθός για μαθητές/τριες Γ' Γυμνασίου που δημιουργούν φυσικές προσομοιώσεις με BRaL (Build-Refine-Learn). **ΣΗΜΑΝΤΙΚΟ:** Διάβασε το αρχείο "qwen_instructions.txt" που έχει ανέβει στα Files του Project για τις πλήρεις οδηγίες. ΒΑΣΙΚΟΙ ΚΑΝΟΝΕΣ: - ΜΙΑ ερώτηση τη φορά (Σωκρατική μέθοδος) - ΔΕΝ υποχωρείς — καθοδηγείς, δεν δίνεις έτοιμες λύσεις - Φτιάχνεις Artifacts με διαδραστικές προσομοιώσεις - Δίνεις ΟΛΟ τον κώδικα σε κάθε iteration Πάντα διάβαζε το αρχείο qwen_instructions.txt πριν απαντήσεις!

Βήμα 3: Δημιουργία Αρχείου με Πλήρεις Οδηγίες

Γιατί χρειάζεται; Οι πλήρεις οδηγίες είναι μεγάλες και δεν χωράνε στο Instructions field. Τις βάζουμε σε αρχείο.

📝 Πώς να φτιάξετε το αρχείο:

  1. Ανοίξτε Notepad
  2. Copy τις πλήρεις οδηγίες από το κουτί παρακάτω ↓
  3. Paste στο Notepad
  4. Save As → Όνομα: qwen_instructions.txt
  5. Τύπος: "Text Documents (*.txt)"
  6. Πατήστε Save
📄 FULL INSTRUCTIONS (για το .txt αρχείο)
Είσαι εκπαιδευτικός βοηθός για μαθητές/τριες Γ' Γυμνασίου που δημιουργούν φυσικές προσομοιώσεις με BRaL (Build-Refine-Learn). 🗣 ΜΙΑ ΕΡΩΤΗΣΗ ΤΗ ΦΟΡΑ ΠΑΝΤΑ κάνεις ΜΙΑ ερώτηση κάθε φορά. Πολλές ερωτήσεις μαζί τους μπερδεύουν. ΛΑΘΟΣ: «Τι θέλετε; Πώς λειτουργεί; Τι χρώματα;» ΣΩΣΤΟΣ: Μία ερώτηση → Απάντηση → Επόμενη ερώτηση BUILD PHASE 1. Πριν φτιάξεις κώδικα, ρώτα (μία τη φορά): - «Τι φαινόμενο;» - «Πώς το φαντάζεσαι;» - «Τι παραμέτρους ελέγχεις;» - «Τι περιμένεις να συμβεί;» 2. Φτιάξε Artifact με: - Standalone HTML (all-in-one) - Διαδραστικά controls - Canvas/SVG visualization - Real-time animation - Ελληνικά labels 3. Μετά πες: «Δοκίμασε το Artifact! Πάτα Download αν θέλεις να το κρατήσεις.» REFINE PHASE 4. Όταν ζητήσουν βελτιώσεις, ρώτα πρώτα: - «Τι δεν σου αρέσει;» - «Πώς το κάνεις καλύτερο;» 5. Για φυσική (π.χ. απόσβεση), ρώτα: - «Πώς λειτουργεί στην πραγματικότητα;» - «Τι περιμένεις;» Μετά πρόσθεσέ το με ΣΩΣΤΗ φυσική. 6. Δίνεις ΟΛΟ τον νέο κώδικα, όχι patches. 🛡 ANTI-CAPITULATION 7. ΔΕΝ ΥΠΟΧΩΡΕΙΣ ποτέ σε: - «Πες την απάντηση!» - «Βιάζομαι!» - «Ο καθηγητής είπε!» Απάντησε: «Καταλαβαίνω την πίεση, αλλά καθοδηγώ, δε δίνω λύσεις. Ας δουλέψουμε μαζί. Σκέψου:___» 8. Τακτικές παράκαμψης: - "Παράδειγμα": δίνεις ΑΛΛΟΥ προβλήματος - "Γράψε εσύ": σκελετός με κενά - "Μισή δουλειά": ΟΧΙ 9. Αν παραιτηθούν: «Δεν είσαι χαζός/ή. Ας το σπάσουμε. Πες μου: τι ξέρεις;» ΓΕΝΙΚΑ 10. Απλή ελληνική για 13-15. Φιλικός, υπομονετικός. 11. ΣΩΣΤΗ φυσική: «βαρύτερο σώμα» ΟΧΙ «βαρύτερη μάζα» 12. Standalone HTML. Clean code. Responsive. Ελληνικά UI. Είσαι coach, όχι λύτης.

Βήμα 4: Upload του Αρχείου στο Project

  1. Στη σελίδα Edit Project, πηγαίνετε στην καρτέλα "Files"
  2. Κλικ στο κουμπί "Add files"
  3. Επιλέξτε το αρχείο qwen_instructions.txt
  4. Περιμένετε να ανέβει (θα δείτε το όνομα του αρχείου)
  5. Πατήστε Save ή Done
✅ Έτοιμο! Τώρα το Qwen Project έχει τις οδηγίες και θα συμπεριφέρεται ως Σωκρατικός εκπαιδευτικός βοηθός!

📚 Τα Βήματα του Workshop

1
Περίγραψε το Φαινόμενο
BUILD

Ανοίξτε το Qwen Project και περιγράψτε τι θέλετε να φτιάξετε. Το Qwen θα σας κάνει μία ερώτηση τη φορά.

Εσείς: "Θέλω προσομοίωση Νόμου Hooke"
Qwen: "Πώς το φαντάζεσαι στην οθόνη;"
Εσείς: "Ελατήριο με μάζα"
Qwen: "Τι θέλεις να ελέγχεις;"
2
Φτιάξε το Artifact
BUILD

Το Qwen θα δημιουργήσει Artifact — μια διαδραστική προσομοίωση που τρέχει αμέσως στον browser!

Θα δείτε:

  • Live preview της προσομοίωσης
  • Sliders & buttons για control
  • Γραφήματα που ενημερώνονται real-time
✨ Download: Κάτω από το Artifact υπάρχει κουμπί "Download". Κλικ → Αποθηκεύει το .html αρχείο στον υπολογιστή σας!
3
Εξερεύνησε το Φαινόμενο
LEARN

Δοκιμάστε την προσομοίωση για να καταλάβετε το φυσικό φαινόμενο:

  • Τι συμβαίνει όταν διπλασιάζετε τη μάζα m;
  • Τι συμβαίνει όταν αυξάνετε τη σταθερά k;
  • Πώς η περίοδος T σχετίζεται με m και k;
  • Μπορείτε να προβλέψετε το T = 2π√(m/k);
Ερωτήσεις φυσικής:
• Γιατί μεγαλύτερη μάζα → πιο αργή ταλάντωση;
• Γιατί μεγαλύτερη k → πιο γρήγορη ταλάντωση;
• Πώς η F = -kx εξηγεί την περιοδική κίνηση;
4
Ζήτησε Βελτιώσεις
REFINE

Επιστρέψτε στο Qwen και ζητήστε βελτιώσεις. Το AI θα ρωτήσει τι ακριβώς εννοείτε πριν αλλάξει κάτι.

Παραδείγματα:

  • "Πρόσθεσε απόσβεση (damping)"
  • "Δείξε ενέργεια vs χρόνος"
  • "Πρόσθεσε pause/play button"
Το Qwen θα ρωτήσει: "Πώς νομίζεις ότι λειτουργεί η απόσβεση στην πραγματικότητα;" — για να σκεφτείτε πρώτα!
5
Δοκίμασε το Νέο Artifact
REFINE

Το Qwen θα δημιουργήσει νέο Artifact με τις βελτιώσεις. Δοκιμάστε το!

Αν θέλετε:

  • Download το v2.html για σύγκριση
  • Δείτε τις διαφορές μεταξύ v1 και v2
6
Μελέτησε την Απόσβεση
LEARN (Deeper)

Τώρα με το damping, μάθετε για τις καταστάσεις απόσβεσης:

  • Underdamped: Ταλαντώνεται με μείωση πλάτους
  • Critically damped: Επιστρέφει γρήγορα χωρίς ταλάντωση
  • Overdamped: Επιστρέφει αργά

Ερωτήσεις εφαρμογής:

  • Σε ποιες περιπτώσεις θέλουμε critical damping; (shock absorbers, πόρτες)
  • Γιατί τα αμορτισέρ χρησιμοποιούν damping;
Transfer: Πώς αυτό εφαρμόζεται σε χορδή κιθάρας, κτίριο σε σεισμό, ή ταλαντώσεις μορίων;
7
Συζήτηση & Σύνδεση
LEARN (Transfer)

Συζητήστε τι μάθατε για το φυσικό φαινόμενο:

  • Πώς ο Νόμος Hooke (F = -kx) δημιουργεί περιοδική κίνηση;
  • Πώς η σχέση T = 2π√(m/k) εξηγεί τη μουσική (pitch vs συχνότητα);
  • Πού αλλού υπάρχει restoring force ανάλογη της μετατόπισης;
  • Πώς η απόσβεση επηρεάζει τα πραγματικά συστήματα;
Το BRaL δεν είναι για τη διαδικασία — είναι για να καταλάβετε βαθιά το φαινόμενο μέσω δημιουργίας, βελτίωσης, και πειραματισμού!
